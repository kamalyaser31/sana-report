# 0004. مراسلة أولياء الأمور عبر روابط واتساب المباشرة (wa.me)

## السياق (Context)
يحتاج المعلم إلى إرسال تقرير الحلقة الفردي وتكليف الواجبات إلى ولي أمر كل طالب مباشرة، مع الرغبة في تجنب التعقيدات التقنية، ورسوم واجهات Meta السحابية، ومخاطر حظر أرقام الهواتف، وتكلفة تشغيل خوادم وسيطة.

## القرار (Decision)
1. إضافة حقل اختياري في بطاقة الطالب باسم (هاتف ولي الأمر) يُحفظ ضمن بيانات الطالب تلقائياً.
2. إضافة زر مقتضب في أسفل بطاقة كل طالب بجانب أزرار الإجراءات باسم (واتساب ولي الأمر).
3. اعتماد روابط واتساب العميقة المباشرة (`https://wa.me/{phone}?text={encodedText}`) لصياغة تقرير الطالب الفردي ودعاء الختام وتعبئته تلقائياً في خانة الكتابة بمحادثة ولي الأمر بنقرة واحدة، ليتولى المعلم ضغط الإرسال في تطبيق واتساب الرسمي.

## المسوغات والبدائل (Consequences & Trade-offs)
- **رُفِضت واجهة Meta Cloud API والخوادم الوسيطة:** لتفادي التكاليف الشهرية ومتطلبات التوثيق ومخاطر الحظر.
- **المزايا:** صفر تكلفة مدى الحياة، وصفر خوادم، وأمان مطلق، وثلاثة أسطر برمجية خفيفة في `students.js` تحقق الغاية بانسيابية تامة.
