# نظام تقارير أكاديمية سنا

تطبيق ويب محلي متكامل لإدارة وصياغة تقارير حلقات القرآن الكريم اليومية لمعلمي أكاديمية سنا، مع إمكانية تصدير التقارير بصيغة PDF ونسخها مباشرة لمشاركتها عبر منصات المراسلة.

## رابط التشغيل المباشر
- **الرابط على GitHub Pages**: [https://kamalyaser31.github.io/sana-report/](https://kamalyaser31.github.io/sana-report/)

## الخصائص والمزايا
1. **حفظ محلي تلقائي**: تُحفظ بيانات الحلقة والطلاب تلقائياً في المتصفح عبر `localStorage`.
2. **صياغة آلية للتقارير**: توليد تقرير منسق يشمل بيانات الحلقة وتفاصيل تسميع ومراجعة وحفظ كل طالب مع الأوسمة والتقييمات.
3. **تصدير مباشر**: تصدير التقرير بضغطة زر إلى ملف PDF أو نسخه إلى الحافظة.
4. **دعم قارئات الشاشة (Accessibility)**: مراعاة معايير إمكانية الوصول والتسميات الدلالية والتنقل السلس بلوحة المفاتيح.

## الاستخدام
- افتح صفحة [index.html](file:///index.html) في أي متصفح ويب حديث دون حاجة لخادم محلي أو حزم خارجية.
- أدخل بيانات الحلقة وتاريخ اليوم واسم المعلم.
- أضف بطاقات الطلاب وسجل درجات التسميع والمراجعة والأوسمة التقديرية.
- انقر على **نسخ التقرير الكلي** أو **تصدير PDF**.
