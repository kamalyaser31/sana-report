# نظام تقارير أكاديمية سنا لتعليم القرآن الكريم

تطبيق ويب خفيف وعصري يعمل محلياً بالكامل (Offline-First) لمساعدة معلمي ومعلمات أكاديمية سنا في إعداد وتوثيق ومشاركة تقارير الحلقات اليومية بيسر وإتقان، مع إمكانية التصدير بصيغة PDF والنسخ المباشر لمنصات المراسلة.

## رابط التشغيل المباشر
- **الرابط على GitHub Pages**: [https://kamalyaser31.github.io/sana-report/](https://kamalyaser31.github.io/sana-report/)

## الخصائص والمزايا الرئيسة
1. **استقلالية تامة دون إنترنت (100% Offline)**: تضمين كافة الملفات والمكتبات محلياً مع عدم الحاجة لأي اتصال بالشبكة.
2. **فصل المسؤوليات (Clean Modular Code)**: تفكيك البنية البرمجية إلى وحدات مستقلة (`index.html` للهيكل، و`styles.css` للتصميم، و`app.js` للمنطق).
3. **تصميم متجاوب ومتوافق مع الهواتف الذكية**: استخدام بطاقات الطلاب بنظام الأكورديون القابل للطي والتوسيع لتوفير مساحة الشاشة وسهولة الإدخال على الهواتف والأجهزة اللوحية.
4. **دعم الوضع الليلي (Dark Mode)**: مظهر مريح للعين أثناء الحلقات المسائية مع حفظ التفضيل تلقائياً.
5. **التكامل المباشر مع استمارة الأتمتة (Cloud Form Auto-Fill)**: تعبئة حقول نموذج Google Forms الستة تلقائياً عبر رابط معبأ مسبقاً (Pre-filled URL) بضغطة زر.
6. **التدوير التلقائي للواجبات (Auto-Rollover)**: تحويل الحفظ الجديد والمراجعة تلقائياً إلى التسميع والمراجعة السابقة لتقرير الجلسة التالية بضغطة زر.
7. **تصدير رسمي بصيغة PDF**: توليد تقرير رسمي نظيف ومنسق خالي من حقول وأزرار التحرير.
8. **التثبيت كتطبيق مستقل (Progressive Web App - PWA)**: إمكانية تثبيت التطبيق على الشاشة الرئيسية للهواتف والحواسيب مع تشغيل فوري دون اتصال بالإنترنت.
9. **دعم كامل لقارئات الشاشة (Accessibility WCAG 2.1 AA)**: اعتماد التسميات الدلالية وسمات ARIA وتوافق التنقل بلوحة المفاتيح.

## هيكل الملفات
- [index.html](file:///index.html): الصفحة الرئيسة وهيكل الواجهة الدلالي.
- [styles.css](file:///styles.css): منظومة الأنماط والألوان الزمردية والتجاوب والطباعة.
- [app.js](file:///app.js): منطق التطبيق وإدارة البيانات والحفظ والتصدير.
- [manifest.json](file:///manifest.json): ملف توصيف تطبيق الويب التقدمي (PWA).
- [sw.js](file:///sw.js): عامل الخدمة للتخزين المؤقت والعمل دون اتصال.
- [icon.svg](file:///icon.svg): أيقونة التطبيق الرسمية.
- `html2pdf.bundle.min.js`: حزمة تصدير ملفات PDF المحلية.
