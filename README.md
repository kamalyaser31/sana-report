# نظام تقارير أكاديمية سنا لتعليم القرآن الكريم

تطبيق ويب خفيف وعصري يعمل محلياً بالكامل (Offline-First) لمساعدة معلمي ومعلمات أكاديمية سنا في إعداد وتوثيق ومشاركة تقارير الحلقات اليومية بيسر وإتقان، مع إمكانية التصدير بصيغة PDF والنسخ المباشر لمنصات المراسلة.

## أدلة الاستخدام والتشغيل
- **دليل المعلمين والمعلمات:** [guide.html](guide.html) (صفحة ويب منسقة ومهيأة للطباعة) أو [USER_GUIDE.md](USER_GUIDE.md) (بصيغة Markdown).
- **رابط التشغيل المباشر:** [https://kamalyaser31.github.io/sana-report/](https://kamalyaser31.github.io/sana-report/)

## الخصائص والمزايا الرئيسة
1. **العمل دون إنترنت (Offline-First)**: الملفات والمكتبات كلها محلية، فيُكتب التقرير بلا شبكة؛ ولا يحتاج الشبكة إلا فتحُ الاستمارة لإرساله.
2. **وحدات مستقلة**: `index.html` للهيكل، و`css/styles.css` للتصميم، وملفات `js/` للمنطق، لكل منها عمل واحد.
3. **تصميم متجاوب ومتوافق مع الهواتف الذكية**: استخدام بطاقات الطلاب بنظام الأكورديون القابل للطي والتوسيع لتوفير مساحة الشاشة وسهولة الإدخال على الهواتف والأجهزة اللوحية.
4. **دعم الوضع الليلي (Dark Mode)**: مظهر مريح للعين أثناء الحلقات المسائية مع حفظ التفضيل تلقائياً.
5. **الإرسال إلى استمارة الأكاديمية**: زر واحد ينسخ التقرير إلى الحافظة ويفتح الاستمارة وفيها المعلم والفئة والساعات والدقائق، فيلصق المعلم التقرير ثم يرسل.
6. **تدوير الواجبات**: زر في بطاقة الطالب ينقل الحفظ الجديد والمراجعة إلى التسميع والمراجعة السابقة للحلقة التالية.
7. **تصدير رسمي بصيغة PDF**: توليد تقرير رسمي نظيف ومنسق خالي من حقول وأزرار التحرير.
8. **منتقي المصحف (Offline Quran Picker)**: اختيار السورة والآيات، أو الصفحات (1-604)، أو الأجزاء (1-30) من مصحف المدينة وإدراجها بنقرة.
9. **التثبيت كتطبيق مستقل (Progressive Web App - PWA)**: إمكانية تثبيت التطبيق على الشاشة الرئيسية للهواتف والحواسيب مع تشغيل فوري دون اتصال بالإنترنت.
10. **دعم كامل لقارئات الشاشة (Accessibility WCAG 2.1 AA)**: اعتماد التسميات الدلالية وسمات ARIA وتوافق التنقل بلوحة المفاتيح.
11. **مسودات متعددة (Multi-Session Drafts)**: لكل حلقة مسودتها في المتصفح، تُحفظ تلقائياً ويُنتقل بينها.
12. **منع أخطاء الإدخال**: لا يُنسخ التقرير ولا يُرسل حتى يكتمل التاريخ ورقم الحلقة والمدة وأسماء الطلاب وتقييماتهم.

├── sw.js                       # عامل الخدمة للتخزين المؤقت والعمل دون اتصال

├── USER_GUIDE.md               # دليل الاستخدام المفصل للمعلمين والمعلمات (Markdown)

├── project_state.md            # الحالة الفنية والذاكرة المعمارية
│
├── css/
│   └── styles.css              # الأنماط والتنسيقات البصرية والوضع الليلي
│
├── js/
│   ├── constants.js            # الثوابت ومصفوفة المعلمين والحقول المعتمدة
│   ├── state.js                # إدارة الحالة والتخزين المحلي
│   ├── ui.js                   # دوال التأمين وإشعارات التوست
│   ├── drafts.js               # إدارة المسودات المتعددة
│   ├── settings.js             # تفضيلات الجلسة وتخصيص الحقول
│   ├── render.js               # بناء وتحديث بطاقات الطلاب
│   ├── students.js             # عمليات الطلاب وتدوير الواجبات
│   ├── report.js               # صياغة وتصدير التقارير وPDF والاستمارة
│   ├── quran.js                # واجهة منتقي المصحف التفاعلية
│   ├── app.js                  # نقطة الانطلاق وربط الأحداث
│   ├── quran-data.js           # محرك وفهرس مصحف المدينة المحلي
