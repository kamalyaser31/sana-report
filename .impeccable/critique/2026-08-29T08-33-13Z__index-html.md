## Overall Impression
A remarkably functional, zero-latency, offline-first Quranic halaqah workbench with high cognitive ergonomics. The core interaction loop is fast and practical. Addressing missing modal/toast CSS rules and refining typography will elevate it from "solid utility" to an impeccable, polished educational tool.

## What's Working
1. **Specialized Quranic Workflow Engine**: The 3-way offline Quran picker and 3-track homework rollover save teachers dozens of clicks per session.
2. **Cognitive Load & Ergonomics**: Collapsible native `<details>` cards, live student counters, and field customization keep the interface clean and focused.
3. **Multi-Channel Publishing Pipeline**: Generates WhatsApp/Telegram ready text, pre-filled Google Form submission URLs, and clean printable PDF reports in 1 click.

## Priority Issues

### [P1] Missing CSS Styling for Toast Notifications (`.toast-msg`)
- **Why it matters**: Feedback for copying, saving, and errors is invisible because `.toast-msg` has no floating CSS rules in `styles.css`.
- **Fix**: Add floating fixed toast styles (`position: fixed; bottom: 80px; left: 50%; transform: translateX(-50%); background: #1a2e35; color: #fff; border-radius: 20px; z-index: 1200;`).
- **Suggested command**: `/impeccable polish`

### [P1] Undefined CSS Variables in Modals (`--bg-header`, `--bg-body`)
- **Why it matters**: Modal headers, tabs, and chips reference undefined CSS variables, resulting in transparent elements over page text.
- **Fix**: Map them to existing variables (`--bg-subtle`, `--bg-card`, `--border`) in `styles.css`.
- **Suggested command**: `/impeccable polish`

### [P2] Missing Modal Keyboard Dismiss (`Escape`) & Focus Trap
- **Why it matters**: Keyboard and screen-reader users cannot dismiss open modals using the `Escape` key.
- **Fix**: Add a `keydown` event listener for `Escape` in `app.js` and autofocus the first interactive element.
- **Suggested command**: `/impeccable harden`

### [P2] Generic Typography Stack
- **Why it matters**: Relying on generic system fonts misses the warmth and legibility of authentic Arabic/Quranic typefaces.
- **Fix**: Incorporate an authentic Arabic font stack (e.g. Readex Pro or Cairo).
- **Suggested command**: `/impeccable typeset`

## Persona Red Flags
- **Alex (Power User / Halaqah Teacher)**: Must click through confirmation dialogs student-by-student; lacks keyboard shortcuts (`Ctrl+N`, `Ctrl+Shift+C`).
- **Jordan (First-Timer Teacher)**: May wonder if "إرسال للاستمارة ↗" immediately posts or opens a review page (needs a small tooltip).
- **Sam (Screen Reader / Accessibility)**: Modals lack focus traps and `Escape` dismiss keys.
- **Casey (Mobile User)**: Modals on smaller mobile screens with the soft keyboard open could clip without smooth scrolling.
